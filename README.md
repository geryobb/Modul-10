# Modul-10
This module is a continuation of module 09, the problem sets in this module focuses on expanding the knowledge of the previous module.
This module also contains the math.sqrt that is a function of the java math class. 
The java math class is a static class, that means we can instantly use it in our code without needing to assign or build it first like the scanner class.
Think of the static class like a plug and play tool, we already have the tool in our disposal so we can instantly use it.
The java scanner on the other hand is like a tool box with parts we can use to build the scanner tool to input our own values. In this example we can need to assemble or build the scanner tool with Scanner = new Scanner(System.in) as well as importing the scanner on the top of the program.
